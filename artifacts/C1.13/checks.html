FR-0.13

In plain words
loop.sh runs one agent turn per pass, bounded by RALPH_TURN_SECS (default 7200). It exits on a STOP file and waits while a HOLD file exists. It gives the agent the row that python -m gates.ledger pick chose. It keeps a log per turn under .ralph/ and appends to ralph.log. When the agent output names a usage limit, it waits for the earliest reset among the failed providers and does not count the turn. Read both dated resets and clock-only resets in the stated zone. A provider with no usable reset uses RALPH_BACKOFF_SECS. Bound the wait with RALPH_MAX_SLEEP_SECS and log the next retry in UTC. The fallback agent runs with --json, and only its own error or turn.failed events count as a limit, including "at capacity". Words in the files it reads do not count. When loop.sh changes on disk, it starts the new copy for the turns left. Before each turn it fetches, checks out main and fast-forwards it to origin/main, so the turn reads the newest prompt, gates and scripts. If it cannot, it stops and sends a note. Agents fall through in a fixed order: Claude, then Codex when RALPH_FALLBACK_BIN is set, then DeepSeek when RALPH_DEEPSEEK_ENV names its settings file. DeepSeek runs the Claude CLI with those settings for that one call and no --model, and its cost is left blank because the CLI prices it at Anthropic rates. The loop moves to the next agent only on a usage limit or a provider error, and sleeps when every agent is limited. A configured agent whose program or settings file is missing stops the loop at start.
