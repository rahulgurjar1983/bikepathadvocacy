FR-0.13

In plain words
loop.sh runs one agent turn per pass, bounded by RALPH_TURN_SECS (default 7200). It exits on a STOP file and waits while a HOLD file exists. It gives the agent the row that python -m gates.ledger pick chose. It keeps a log per turn under .ralph/ and appends to ralph.log. When the agent output names a usage limit, it sleeps until the stated reset (or RALPH_BACKOFF_SECS) and does not count the turn. The fallback agent runs with --json, and only its own error or turn.failed events count as a limit, including "at capacity". Words in the files it reads do not count. When loop.sh changes on disk, it starts the new copy for the turns left. Before each turn it fetches, checks out main and fast-forwards it to origin/main, so the turn reads the newest prompt, gates and scripts. If it cannot, it stops and sends a note.
